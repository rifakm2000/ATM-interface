# 🏦 Python ATM System (Tkinter + SQLite)

A simple yet **secure ATM application** built with **Python, Tkinter GUI, and SQLite database**.  
This project simulates the working of an ATM machine including account creation, login, deposits, withdrawals, transfers, mini-statements, PIN management, and admin controls.

## ✨ Features

✅ **User Functions**
- Create new account with initial deposit  
- Login securely using PIN (PBKDF2-HMAC-SHA256 hashing + salt)  
- Deposit, withdraw, and transfer funds  
- View real-time balance updates  
- Mini-statement (last 10 transactions)  
- Change PIN securely  

✅ **Admin Functions**
- Admin login (with password)  
- View all accounts and balances  
- Reset user PINs  

✅ **Tech Stack**
- **Frontend/UI** → Tkinter (Python GUI)  
- **Backend/Database** → SQLite  
- **Security** → PBKDF2 PIN hashing with random salt
